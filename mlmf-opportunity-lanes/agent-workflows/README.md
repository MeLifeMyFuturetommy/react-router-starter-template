# Agent Workflows Lane

Status: opportunity lane
Purpose: store bounded agent-use patterns before they become standard practice.

## Belongs here

- C5 Codex build patterns
- C3 verification patterns
- C2 continuity handoff patterns
- Antigravity, Gemini, Manus, Grok, Perplexity, NotebookLM, and browser-agent tests
- shutdown and restart routines for computer-bound work

## Does not belong here

- broad authority grants
- unbounded agent instructions
- hidden background work claims
- private source material

## Evidence rule

Each agent workflow should record actor, tool, allowed inputs, blocked inputs, action power, proof captured, and shutdown requirement.

## Promotion rule

An agent workflow becomes standard only after a repeatable test and proof review.
