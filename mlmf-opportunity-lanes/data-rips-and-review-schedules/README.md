# Data Rips and Review Schedules Lane

Status: opportunity lane
Purpose: plan controlled review passes through Gmail, Drive, GitHub, Slack, Wisebase, and other stack surfaces.

## Belongs here

- review slices
- source search terms
- scheduling ideas
- history marker passes
- evidence capture checklists
- missed-variant search plans

## Does not belong here

- raw private data exports
- source mutation instructions
- unbounded scraping plans
- C-drive review plans unless C1 says the computer-side C drive is on

## Evidence rule

Each review slice should record source, search terms, time range, reason, output expected, proof captured, and revisit cadence.

## Promotion rule

A review schedule becomes active only when it is bounded, useful, and approved by C1.
