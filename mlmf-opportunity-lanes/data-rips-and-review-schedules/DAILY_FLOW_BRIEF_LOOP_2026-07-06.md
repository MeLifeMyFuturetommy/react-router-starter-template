## Purpose

Every MLMF brief should feed the Flow Method / Agentic Command Library. The brief comes first. The method-growth pass comes after the brief.

## Standing loop

1. Write the brief.
2. Find the latest Flow Method / Agentic Command Library document from Gmail or the current known email thread.
3. Read the current document state.
4. Identify what the brief revealed.
5. Add improvements additively.
6. Include new command variants, missing flow patterns, old useful functions, or agent-specific versions where useful.
7. Send the improved version back to the email lane.
8. Include a self-note saying what changed, where the document is up to, and what the next batch should cover.
9. Keep moving if one graph or format blocks. Mark that item pending and continue with the next useful form.
10. Do not overwrite source truth silently.
