# Connector Opportunities Lane

Status: opportunity lane
Purpose: capture safe uses for connected services before they become operational routes.

## Belongs here

- Gmail routing ideas
- Google Drive document lanes
- GitHub build and proof lanes
- Slack coordination lanes
- Wisebase knowledge retrieval checks
- Airtable, Zapier, SharePoint, Calendar, and other connector possibilities

## Does not belong here

- unchecked access assumptions
- private content dumps
- broad connector authority
- production changes without a named task

## Evidence rule

Each connector opportunity should record service, action type, read or write power, data touched, proof state, and current access status.

## Promotion rule

A connector route becomes active only after least-privilege review and a small proof run.
