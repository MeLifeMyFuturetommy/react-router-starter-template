# Applications Lane

Status: opportunity lane
Purpose: store app ideas, app skeletons, product experiments, MVP candidates, and future build openings.

## Belongs here

- small web app concepts
- operator tools
- workflow helpers
- future MLMF product apps
- app architecture notes
- build-ready briefs for C5

## Does not belong here

- credentials
- private source truth
- raw C-drive material
- unreviewed personal data
- production secrets

## Evidence rule

Each app opportunity should record problem, user, input, output, tool stack, risk, proof needed, and promotion state.

## Promotion rule

An application moves from idea to build only after C1 direction and C3 proof gate.
