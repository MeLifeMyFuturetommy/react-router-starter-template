# Multi-Workflow Situations Lane

Status: opportunity lane
Purpose: capture places where one MLMF outcome may require several tools working together.

## Belongs here

- Gmail to Drive to GitHub flows
- Slack to GitHub coordination flows
- Drive to C5 build-pack flows
- AI tool chains involving Codex, Gemini, Manus, Grok, Perplexity, Antigravity, NotebookLM, or other agents
- operator workflows that cross multiple apps

## Does not belong here

- final SOP text
- untested automations
- private source copies
- unsupported claims

## Evidence rule

Each workflow should record trigger, tools involved, data touched, output, risk, proof needed, and rollback or stop condition.

## Promotion rule

A workflow becomes active only after a small sandbox run and C3 review.
