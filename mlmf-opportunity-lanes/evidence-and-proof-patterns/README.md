# Evidence and Proof Patterns Lane

Status: opportunity lane
Purpose: store reusable proof patterns that help C3 verify work without turning every proof note into a full SOP.

## Belongs here

- screenshot proof patterns
- timestamp proof patterns
- path and hash proof patterns
- Gmail evidence patterns
- GitHub commit and branch proof patterns
- Drive mirror and manifest proof patterns

## Does not belong here

- original source files
- final SOPs
- unsupported claims
- private data copies

## Evidence rule

Each proof pattern should describe what it proves, what it does not prove, required fields, and failure signs.

## Promotion rule

A proof pattern becomes standard only when C2 turns the stable pattern into SOP/doctrine or C1 explicitly approves it.
