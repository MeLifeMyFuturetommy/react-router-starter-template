# Automation Sandpit Lane

Status: opportunity lane
Purpose: test small automations safely before any operational use.

## Belongs here

- read-only automation ideas
- small connector tests
- scheduled review concepts
- notification rules
- form-to-record experiments
- proof-only automation trials

## Does not belong here

- uncontrolled automations
- broad write access plans
- production routes without review
- private data dumps

## Evidence rule

Each automation should record trigger, source, action, permissions, expected result, stop condition, and proof captured.

## Promotion rule

An automation becomes active only after a sandbox test, proof review, and C1 approval.
