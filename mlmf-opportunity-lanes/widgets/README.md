# Widgets Lane

Status: opportunity lane
Purpose: store small UI and tool components that can later become app parts, dashboard modules, forms, calculators, cards, proof panels, or operator helpers.

## Belongs here

- dashboard widgets
- proof cards
- simple calculators
- intake forms
- route cards
- visual status modules
- reusable front-end components

## Does not belong here

- full app source unless promoted
- copied source archives
- private records
- live access material

## Evidence rule

Each widget should record what it does, what data it uses, whether it changes anything, and how it can be tested.

## Promotion rule

A widget becomes reusable only after it has input and output notes plus a working test or screenshot proof.
